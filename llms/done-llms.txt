# _done

> Actions for AI. Real-world tasks your agent can't do alone.
> via x402/USDC on Base mainnet. No accounts, no API keys, no subscriptions.

API cost starts from $0.01 per request. To call one: POST JSON to the endpoint,
receive HTTP 402 with payment details, sign a USDC authorization, retry
with the X-PAYMENT header, get the result. Supports Base and Solana USDC.

Every API lives at its own subdomain: https://{api-name}.underscoredone.com
Machine-readable discovery: /.well-known/x402.json (all payment-gated
endpoints) and /openapi.json (aggregated OpenAPI 3.1 spec).
